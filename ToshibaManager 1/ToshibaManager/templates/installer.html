ÉTAPE 1

Le copieur

Laissé vide, le modèle est détecté en SNMP sur place et le pilote en est déduit. Renseignez-le seulement pour les copieurs dont le SNMP est coupé : il servira alors de repli, sans rien à saisir sur le poste.

🎨

ÉTAPE 2

Réglages par défaut

Appliqué aux deux jeux de réglages : les Préférences d'impression de l'utilisateur et les Paramètres par défaut de l'impression de la machine. Le format A4 et l'impression intelligente sont appliqués dans tous les cas.

Sur le poste de l'utilisateur
  1. Enregistrez le fichier généré et double-cliquez dessus.
  2. Acceptez l'élévation UAC.
  3. Le script interroge le copieur, affiche le modèle détecté et le pilote retenu, et demande confirmation. Si le SNMP ne répond pas, il demande le modèle.
  4. Il installe ensuite le pilote, crée le port TCP/IP, nomme la file TOSHIBA <MODELE>, applique les réglages et la définit comme imprimante par défaut.
