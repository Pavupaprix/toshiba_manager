3 — Configuration Windows

⚙️

RÉGLAGES

Système

Attention. La désactivation complète (EnableLUA=0) empêche toutes les applications du Store de s'ouvrir — Paramètres, Photos, Calculatrice comprises — et exige un redémarrage. « Ne plus demander de confirmation » donne le même confort sans cet effet de bord.

👤

PROFILS

Comptes locaux

Un mot de passe laissé vide crée un compte sans mot de passe. La connexion automatique fonctionne aussi dans ce cas — le poste s'ouvre alors directement sur le bureau, sans rien demander. Avec un mot de passe, elle l'inscrit en clair dans le registre : à réserver aux postes en libre-service.

    Postes à ranger

    Ces postes portent déjà ce TAG mais leur fiche est restée dans une autre entité : GLPI n'applique ses règles d'affectation qu'à la création. Transférez-les depuis leur fiche, avec votre modèle habituel.

      Renseigné après la vérification dans GLPI.

      Sur le poste de l'utilisateur
      1. Décompressez le ZIP sur le poste, puis double-cliquez sur Installer-Poste.bat.
      2. Acceptez l'élévation UAC.
      3. Le script installe les applications, applique les réglages Windows et crée les comptes, puis affiche un résumé.
      4. Il propose enfin de supprimer le dossier : répondez oui, c'est ce qui efface les mots de passe du poste. Le journal, lui, est conservé dans %ProgramData%\OMB\InstallationPoste et ne contient aucun mot de passe.
